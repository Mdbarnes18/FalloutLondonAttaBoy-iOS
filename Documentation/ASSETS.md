# Asset provenance and usage

- The approved ATTA-Boy/app icon artwork from the original FalloutLondonCompanion repository is locked. Do not regenerate, recolor, replace, resize or otherwise alter the source artwork without explicit approval.
- Android and desktop CI download the exact approved PNG from the pinned source commit `b2e544f4279ddfbe3184b573de04b4104906f7f3` and use it only in packaging.
- The original project SVG artwork remains available at [FalloutLondonCompanion SVG](https://github.com/Mdbarnes18/FalloutLondonCompanion/blob/main/docs/FalloutLondonCompanion.svg). It is separate from the app icon and is not used as a substitute for a verified Fallout: London world map.
- User-supplied ATTA-Boy reference images are distinct from Fallout Wiki archives. Individual assets must be evaluated for their own redistribution terms.
- Bethesda/Fallout assets and Team FOLON assets remain separate. Permission for one set does not imply permission for the other.
- Private Discord conversations, screenshots, usernames and permission correspondence are not included in this repository.
