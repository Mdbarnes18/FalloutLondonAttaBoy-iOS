# Asset provenance and usage

- The approved ATTA-Boy app icon is preserved unchanged at [Assets/AppIcon-Original.png](../Assets/AppIcon-Original.png). It is the exact 1024 × 1024 PNG from the original companion repository (SHA-1 blob: `0bf7632af2ad96d7b35961009b83f076efbab129`).
- The README displays that same PNG. Do not regenerate, recolor, crop, replace or alter the master artwork.
- Platform package formats may require derived size variants. Resize copies only; keep `Assets/AppIcon-Original.png` untouched. See the size guidance in the README/release documentation.
- Android and desktop CI currently fetch the same approved PNG from the pinned original repository commit; the local master copy is retained so the new repository no longer depends on the old repository for the source icon.
- The original project SVG artwork in the old repository is separate branding artwork, not the app icon. It is not used as the application icon or as a verified Fallout: London world map.
- User-supplied ATTA-Boy reference images are distinct from Fallout Wiki archives. Individual assets must be evaluated for their own redistribution terms.
- Bethesda/Fallout assets and Team FOLON assets remain separate. Permission for one set does not imply permission for the other.
- Private Discord conversations, screenshots, usernames and permission correspondence are not included in this repository.
